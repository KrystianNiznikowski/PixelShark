# Moja Firma

Prosta strona internetowa typu onepage(zadanie na praktykach).

## Opis projektu

Strona przedstawia przykładową firmę zajmującą się tworzeniem prostych stron internetowych.

Na stronie znajdują się:
-sekcja główna
-sekcja „O nas
-sekcja „Usługi
-sekcja „Kontakt
-menu nawigacyjne
-stopka
-prosta interakcja JavaScript

## Języki

Projekt został wykonany przy użyciu:

 HTML
CSS
JavaScript

## Funkcjonalności

Menu nawigacyjne

Przycisk Dowiedz się więcej uruchamia funkcję JavaScript, która wyświetla dodatkowy tekst

Strona jest responsywna i dostosowana do telefonu
